# 📊 Quiz Tracker

A modern, easy-to-use web app built with **React**, **Firebase**, and **Tailwind CSS** to help students effectively **track quizzes**, **identify mistakes**, and **analyze performance** across subjects and topics.

## 🚀 Live Demo

👉 [Quiz Tracker Web App](https://quiztracker-da338.web.app/)

---

## 📌 Problem It Solves

Many students rely on Excel sheets to track their test series progress, identify mistakes, and log marks — a method that is functional but cumbersome and uninspiring.

**Quiz Tracker** replaces this with a user-friendly interface designed to:

- Track which quizzes/tests have been taken
- Log and review mistakes
- Record obtained marks
- Analyze performance per subject and even by topic

---

## ✨ Features

### ✅ Quiz Tracking
- Mark quizzes as taken or pending
- Add remarks or notes for each quiz
- Store marks obtained for future reference

### 🔍 Mistake Management
- Log mistakes for each quiz
- Review common errors and avoid repeating them

### 📈 Subject & Topic Analysis
- Visual breakdown of performance by **subject**
- Drill down to see performance on specific **topics**
- Helps identify strong and weak areas

### 💡 Intuitive UI
- Clean and modern interface using **Tailwind CSS**
- Designed to reduce mental load and make tracking enjoyable

---

## 🛠️ Tech Stack

- **Frontend:** React
- **Styling:** Tailwind CSS
- **Backend/Database:** Firebase (Authentication + Firestore)
- **Hosting:** Firebase Hosting
